GanttManagementSheet

A Google Sheets project management add-on designed for task scheduling, Gantt chart visualization, workload management, Kanban tracking, and project reporting directly inside Google Sheets.

Google Sheets Apps Script Project Management Kanban Gantt Chart

Overview

GanttManagementSheet is a Google Workspace add-on built using Google Apps Script to help teams manage projects without leaving Google Sheets. It combines scheduling automation, Kanban boards, Gantt charts, reporting tools, and workload analysis into a single spreadsheet-based system.

Main Features

Automatic Scheduling

Generate task schedules automatically using dependencies, start dates, durations, and priorities.

Gantt Chart View

Visualize project timelines and progress directly inside Google Sheets.

Kanban Board

Organize tasks into workflow stages for easier team tracking.

Workload Analysis

Monitor team capacity and balance assignments efficiently.

Performance Reporting

Generate reports to evaluate project execution and productivity.

Google Workspace Integration

Works directly inside Google Sheets using Google Apps Script and Workspace APIs.

How It Works

1. Create Projects

Add projects, milestones, and tasks inside Google Sheets.

2. Schedule Automatically

Generate schedules and dependencies automatically using built-in logic.

3. Track Progress

Monitor tasks using Gantt charts, Kanban boards, and reports.

Permissions & OAuth Usage

  • Spreadsheet permissions are used to manage project data, schedules, and reports.
  • Google Drive access is used for saving templates and reports.
  • User authorization is required for Google Workspace integration.
  • Data is processed inside Google Workspace services.

Why Use GanttManagementSheet?

Many teams already collaborate using Google Sheets but still rely on external project management tools. GanttManagementSheet brings scheduling, visualization, and reporting directly into the spreadsheet workflow, reducing complexity and improving collaboration.
