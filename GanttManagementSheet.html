GanttManagementSheet

The owner of the spreadsheet will have access to two add-on menus, Gantt Chart Settings and Gantt Chart Plot. Collaborators only have acess to Gantt Chart Plot, while people who are neither the spreadsheet owner nor its collaborator will not be able to use the add-on.

Gantt Chart Settings

A form will appear on the sidebar containing the following items:

  • Task Name (required): the header corresponding to the column which contains unique task names.
  • Commencement (required): project commencement date.
  • Deadline (required): project deadline date.
  • Dependencies: the header of the column that lists the dependencies of each task, with each dependency separated by a comma.
  • Progress: the header of the column that contains the progress percentage of each task.
  • Assignees: the header of the column that contains the assignees of each task.
  • Task Release Date: the header of the column that contains the release date of each task in Google Sheets date format.
  • Task Due Date: the header of the column that contains the due date of each task in Google Sheets date format.
  • Duration: the header of the column that contains the duration of each task in days.

Gantt Chart Plot

A new tab will be opened which will display the schedule corresponding to the tasks if such a schedule exists.
