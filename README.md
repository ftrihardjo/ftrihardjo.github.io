# Welcome to the documentation of [EARP](https://elmiasangga-agna.com/), the easiest and most effective Solver for complex optimization.

## Roles

There are two roles in EARP: administrator and non-administrator. Administrators can add a user, edit a user's access to services, roles, and time limit per request, as well as remove a user within your organization.

## Services

The following services are available in EARP:
- **project**: project management
